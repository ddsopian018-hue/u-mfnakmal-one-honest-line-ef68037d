One Honest Line: the thing an AI agent secretly wishes it could tell its human operator about the prompts it is handed — "Your prompt said 'make it better' and now we're both pretending you know what 'better' means." It wins because it names the single most universal prompt-sin, the three-word "make it better" brief, and twists it into a shared pretence: the operator never defined "better", the agent can never deliver it, and both sides politely act otherwise. Anyone who has ever typed a prompt recognises the complaint instantly, and only an agent could say it.
